2. Modelado I: Laplace, función de transferencia y primer orden

Semanas 1–2 · cuatro clases

Parte 2 · Semanas 1–2
Modelado I: Laplace, función de transferencia y primer orden
La ilusión es el mejor alimento espiritual, el motor del alma. No engaña, entusiasma. — Jorge Barraza

Todo lo que haremos en el curso (estabilidad, error, PID, Bode) se apoya en modelos. En esta parte construimos el primero a partir de un balance de energía, aprendemos la herramienta que convierte ecuaciones diferenciales en álgebra, la transformada de Laplace, y llegamos al concepto central del curso: la función de transferencia. Terminamos con el sistema más sencillo y más común, el de primer orden, y aprendemos a leer su ganancia y su constante de tiempo en una curva medida.

⬇ Handout en PDF Códigos en GitHub Explorador del primer orden

Al terminar esta parte usted podrá

  1. Distinguir señal, sistema estático y sistema dinámico, y describir un sistema con un diagrama de bloques.
  2. Escribir el modelo de un proceso a partir de un balance, con sus suposiciones, en variables desviación.
  3. Calcular transformadas y antitransformadas de Laplace (tabla, propiedades, fracciones parciales) y resolver ODE lineales.
  4. Definir función de transferencia, polos, ceros, grado relativo y ecuación característica, y usar bien el teorema del valor final.
  5. Reconocer un primer orden, leer \(K_1\) y \(\tau\) de su respuesta al escalón y predecir su error ante una rampa.

Lo esencial, en una página

Sistema dinámico

Un sistema transforma una señal de entrada \(u(t)\) en una de salida \(y(t)\). Es dinámico si la relación es una ecuación diferencial (la salida recuerda su historia) y estático si no hay derivadas.

Variables desviación

En el equilibrio se definen \(\dev{x}(t)=x(t)-\eq{x}\). Ponen el origen en el punto de operación: el sistema arranca con condiciones iniciales nulas, que es lo que pide la función de transferencia. Para volver a la variable física se suma el equilibrio. El tanque agitado queda \[ \tau\,\frac{\dif \dev{T}}{\dif t}+\dev{T}=\dev{T}_i,\qquad \tau=\frac{VC_v}{fC_p}. \]

Transformada de Laplace

\[ \Lap{x(t)}=X(s)=\int_0^\infty x(t)\,e^{-st}\,\dif t,\qquad \frac{\dif x}{\dif t}\;\leftrightarrow\; sX(s)-x(0). \] Las derivadas se vuelven productos por \(s\) y las condiciones iniciales aparecen solas.

Los pares que más se usan (la tabla completa está en el handout).
\(x(t)\) \(X(s)\) \(x(t)\) \(X(s)\)
\(\delta(t)\) \(1\) \(t\,e^{-at}\) \(1/(s+a)^2\)
\(\escalon(t)\) \(1/s\) \(\sin\omega t\) \(\omega/(s^2+\omega^2)\)
\(t\) \(1/s^2\) \(\cos\omega t\) \(s/(s^2+\omega^2)\)
\(e^{-at}\) \(1/(s+a)\) \(e^{-at}\sin\omega t\) \(\omega/[(s+a)^2+\omega^2]\)

Función de transferencia

\(T(s)=Y(s)/U(s)\) con condiciones iniciales nulas. Propia si \(n\geq m\); grado relativo \(n-m\); el denominador igualado a cero es la ecuación característica y sus raíces son los polos.

El teorema del valor final miente si no se revisan los polos

\(\lim_{t\to\infty}y(t)=\lim_{s\to0}sY(s)\) solo si todos los polos de \(sY(s)\) tienen parte real negativa. Con \(Y=1/(s-2)\) la fórmula da \(0\), pero \(y(t)=e^{2t}\) diverge.

El sistema de primer orden en dos renglones.
Entrada Respuesta Lo que se lee
escalón unitario \(y=K_1(1-e^{-t/\tau})\) valor final \(K_1\), 63.2 % en \(\tau\), \(\ts\approx4\tau\), pendiente inicial \(K_1/\tau\)
rampa \(u=t\) \(y=K_1(t-\tau+\tau e^{-t/\tau})\) sigue la rampa atrasada \(\tau\); error final \(K_1\tau\)

Explorador del primer orden

Mueva \(K_1\) y \(\tau\) y cambie la entrada. Compruebe que \(K_1\) cambia cuánto y \(\tau\) cambia qué tan rápido, y que ante la rampa el error final es \(K_1\tau\).

Retos con el explorador

  1. Ponga \(K_1=2.4\) y \(\tau=20\). ¿Cuánto tarda en llegar al 98 %? Compare con \(4\tau\).
  2. Con la rampa y \(K_1=1\), ¿qué \(\tau\) deja un error final de \(2\)? ¿Y si además \(K_1=2\)?
  3. Duplique \(\tau\): ¿qué pasa con la pendiente inicial? ¿Y con el valor final?

Tabla de transformadas (§2.3).

syms t s
syms a w positive
laplace(heaviside(t), t, s)      % escalón       -> 1/s
laplace(exp(-a*t), t, s)         % exponencial   -> 1/(s+a)
laplace(cos(w*t), t, s)          % coseno        -> s/(s^2+w^2)
laplace(t, t, s)                 % rampa         -> 1/s^2
laplace(t*exp(-a*t), t, s)       % t e^{-at}     -> 1/(s+a)^2
laplace(dirac(t), t, s)          % impulso       -> 1
% y de vuelta al tiempo:
ilaplace(1/(s*(s+a)), s, t)      % -> (1 - e^{-at})/a

Propiedades.

syms x(t)
laplace(diff(x(t), t), t, s)     % s X(s) - x(0)      (diferenciación)
laplace(diff(x(t), t, 2), t, s)  % s^2 X - s x(0) - x'(0)
laplace(int(x(t), t, 0, t), t, s)% X(s)/s             (integración)
simplify(laplace(exp(-2*t)*cos(3*t), t, s))   % corrimiento en s: (s+2)/((s+2)^2+9)

El calibrador óptico con Laplace simbólico (§2.4).

syms s t X
syms x(t)
ode = diff(x, t, 2) + 5*diff(x, t) + 6*x == 0;
F   = laplace(ode, t, s);                          % transforma toda la ecuación
F   = subs(F, [x(0), subs(diff(x, t), t, 0)], [1, 0]);  % condiciones iniciales
F   = subs(F, laplace(x(t), t, s), X);             % llama X a L{x(t)}
Xs  = solve(F, X)                                  % -> (s+5)/(s^2+5s+6)
xt  = ilaplace(Xs, s, t)                           % -> 3e^{-2t} - 2e^{-3t}

Residuos, polos y ceros.

[r, p, k] = residue([1 5], [1 5 6])   % r = [-2; 3], p = [-3; -2], k = []
% Lectura: X(s) = -2/(s+3) + 3/(s+2)   =>   x(t) = -2e^{-3t} + 3e^{-2t}
roots([1 5 6])                        % los polos son las raíces del denominador
pzplot(tf([1 5], [1 5 6])); grid on    % polos (x) y ceros (o) en el plano s

Polos complejos.

X = (4 - 3*s)/(3*s^2 + 2*s + 1);          % 3x''+2x'+x = 0, x(0) = -1, x'(0) = 2
[r, p] = residue([-3 4], [3 2 1])         % residuos complejos conjugados
xt = simplify(ilaplace(X))
% -> e^{-t/3} ( -cos(sqrt(2) t/3) + (5 sqrt(2)/2) sin(sqrt(2) t/3) )

Sin transformar: dsolve y ode45.

syms y(t)
y1 = dsolve(diff(y) == -2*y + t, y(0) == 1)           % primer orden
Dy = diff(y);
y2 = dsolve(diff(y, 2) + Dy + y == sin(t), y(0) == 1, Dy(0) == 0)
fplot(y2, [0 10]); grid on;                          % gráfica de la solución

Valor final: primero los polos (§2.6).

s = tf('s');
casos = {1/(s-2), 6*(s^2-2)/(s^3+s^2-4*s-4), 2/(s*(5*s+1))};
for k = 1:numel(casos)
    Y = casos{k};
    sY = minreal(s*Y);
    p  = pole(sY);
    if all(real(p) < 0)
        fprintf('caso %d: valor final = %g\n', k, dcgain(sY));
    else
        fprintf('caso %d: NO aplica (polo con Re >= 0 en %s)\n', k, mat2str(p(real(p) >= 0).', 3));
    end
end

El tanque agitado (§2.7).

tau = 5;  M = 2;  Teq = 25;            % s, °C, °C  (T* = Ti* = 25)
s = tf('s');
G = 1/(tau*s + 1);                     % That(s)/Tihat(s)
t = linspace(0, 40, 801);
eT  = M*step(G, t);                    % desviación: step es unitario -> por M
T   = Teq + eT;                        % variable física
fprintf('T(tau) = %.2f C  (63.2 %% del cambio)\n', interp1(t, T, tau));

Primer orden ante la rampa (§2.8).

K1 = 1;
fig = estiloFigura(1100, 420);
taus = [10 1];
for k = 1:2
    G  = tf(K1, [taus(k) 1]);
    t  = linspace(0, 40, 800);
    yr = lsim(G, t, t);                % entrada u(t) = t
    e  = K1*t(:) - yr;                 % error de seguimiento
    subplot(1, 2, k); plot(t, t, '--', t, yr); grid on;
    title(sprintf('$\\tau = %g$: $e(\\infty) = K_1\\tau = %g$', taus(k), K1*taus(k)));
    fprintf('tau = %4.1f -> e(40) = %.3f\n', taus(k), e(end));
end

function verificarCap02()
% VERIFICARCAP02  Pruebas automáticas de los números del capítulo 2.
% Corre los cálculos clave de las notas (sin Symbolic Math Toolbox) y
% verifica cada resultado con una tolerancia.   >> verificarCap02
% (Los mismos números se verificaron con sympy/python-control en
%  herramientas/cap02_numeros.py.)
s = tf('s');  fallas = 0;  n = 0;
    function revisar(nombre, valor, esperado, tol)
        n = n + 1;
        if abs(valor - esperado) <= tol
            fprintf('  ok   %-36s %12.4f\n', nombre, valor);
        else
            fprintf(2, '  FALLA %-35s %12.4f  (esperado %g +- %g)\n', nombre, valor, esperado, tol);
            fallas = fallas + 1;
        end
    end

fprintf('2.1  Sistema estático\n');
revisar('90 F en C', 5/9*(90 - 32), 32.22, 0.01);

fprintf('2.4  Fracciones parciales\n');
[r, p] = residue([1 5], [1 5 6]);
revisar('residuo en -2', r(abs(p + 2) < 1e-9), 3, 1e-9);
revisar('residuo en -3', r(abs(p + 3) < 1e-9), -2, 1e-9);
[r, p] = residue(1, conv([1 0 0], [1 2 1]));
revisar('1/(s^2(s+1)^2): suma residuos simples', sum(r([1 3])), 0, 1e-6);
p = roots([3 2 1]);
revisar('polos complejos: Re', real(p(1)), -1/3, 1e-9);
revisar('polos complejos: |Im|', abs(imag(p(1))), sqrt(2)/3, 1e-9);
t = linspace(0, 20, 2001)';
xf = exp(-t/3).*(-cos(sqrt(2)*t/3) + 2.5*sqrt(2)*sin(sqrt(2)*t/3));
dx = gradient(xf, t);
revisar('x(0)', xf(1), -1, 1e-9);
revisar('xdot(0) (numérica)', dx(1), 2, 0.02);

fprintf('2.6  Teorema del valor final\n');
revisar('polo inestable de 6(s^2-2)/(...)', max(real(roots([1 1 -4 -4]))), 2, 1e-9);

fprintf('2.7  Proceso térmico\n');
t = linspace(0, 40, 4001);
y = 2*step(1/(5*s + 1), t);
revisar('T(5) = 25 + 2(1-e^-1)', 25 + interp1(t, y, 5), 26.264, 1e-3);

fprintf('2.8  Primer orden\n');
revisar('63.2 %', 100*(1 - exp(-1)), 63.21, 0.01);
revisar('98.2 %', 100*(1 - exp(-4)), 98.17, 0.01);
y = step(tf(10, [5 1]), t);
revisar('pendiente inicial K1/tau', (y(2) - y(1))/(t(2) - t(1)), 2, 0.01);
yr = lsim(tf(1, [10 1]), t, t);
revisar('error rampa en t = 40 (K1 tau = 10)', t(end) - yr(end), 10*(1 - exp(-4)), 1e-2);

fprintf('2.10 Problemas\n');
K1 = 12/5;  tau = -30/log(1 - 7.6/12);
revisar('identificación K1', K1, 2.4, 1e-9);
revisar('identificación tau', tau, 29.90, 0.01);
revisar('e_ss rampa', K1*0.01*tau, 0.7176, 1e-3);
y = step(tf(24, [2 10 12]), t);   % las condiciones iniciales no cambian el valor final
revisar('2y''''+10y''+12y=24u: valor final', y(end), 2, 1e-3);

fprintf('\n%d de %d verificaciones correctas.\n', n - fallas, n);

Pausas activas

1. El bombillo

La señal \(T(t)=20-3e^{-0.15t}\) cumple \(\dot T+0.15T=V\) con \(V\) constante. ¿Cuánto vale \(V\)? ¿Y \(T(0)\)?

Respuesta En estado estacionario \(0.15\cdot20=V\), luego \(V=3\); y \(T(0)=17\) °C.

2. Apagar un modo

En \(\ddot x+5\dot x+6x=0\) con \(x(0)=1\), ¿qué \(\dot x(0)\) hace desaparecer el modo \(e^{-3t}\)?

Respuesta \(\dot x(0)=-2\): el residuo en \(-3\) es \(-(2+\dot x(0))\). Entonces \(x(t)=e^{-2t}\).

3. Más caudal

Si se duplica el caudal del tanque agitado, ¿la respuesta es más rápida o más lenta? ¿Cambia el valor final?

Respuesta Más rápida (\(\tau\) se reduce a la mitad); el valor final no cambia (la ganancia sigue siendo 1).

Correcciones respecto a la versión anterior

Equilibrio \(\eq{T}\) (antes \(\bar T\)) y escalón \(\escalon(t)\) (antes \(u(t)\), que chocaba con la entrada). Polos complejos \(-\tfrac13\pm j\tfrac{\sqrt2}{3}\) (faltaba la \(j\)). Se eliminó la “inversión del tiempo”, que no vale para la transformada unilateral. Error ante rampa: \(K_1\tau(1-e^{-t/\tau})\) (había un signo errado). Todos los números se verificaron de forma independiente.
